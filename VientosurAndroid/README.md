# VientosurAndroid

Starter Android project for the Vientosur app.

## Overview
This project was uploaded from the `VientosurAndroid-Starter.zip` archive and contains a minimal Android application structure ready to be expanded.

## Requirements
- Android Studio
- JDK 17+
- Android SDK

## Run locally
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Select the `app` configuration and run it.

## Project structure
- `app/` - application code and resources
- `.github/workflows/android.yml` - CI workflow to build the app
